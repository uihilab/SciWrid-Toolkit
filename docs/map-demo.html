    Upload a file

    Choose a supported scientific data file from the File picker in the sidebar.

    Load a real dataset to try the toolkit end to end. GFS forecast is four timesteps, three hours apart. Hurricane Idalia (2023) is three real products in three formats — NCEP Stage IV radar QPE (GRIB2), NOAA AORC (Zarr) and NLDAS-2 (NetCDF). The NLDAS file also carries 10 m wind: drag it to the top of the file list to make it primary, pick “Wind speed”, and press play to watch the storm’s wind field animate. Click the map and choose “Show analysis” to chart how the products compare at that point.
